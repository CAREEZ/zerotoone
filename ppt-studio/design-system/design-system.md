# 디자인 시스템 (공통)

모든 덱에 적용하는 고정 규칙. 덱마다 바꾸지 않는다. 바꿀 때는 이 파일을 고치고 `lessons-log.md`에 사유를 남긴다.

## 1. 포맷
| 용도 | 규격 | 비고 |
|---|---|---|
| 발표·IR·강의 | 16:9 (13.333 × 7.5 in) | 기본값 |
| 기관 제출(인쇄·PDF) | A4 가로 또는 A4 세로 | **기관 지정 양식이 있으면 양식이 최우선** |
| 산출물 | `.pptx`(편집용) + `.pdf`(제출·공유용) | 둘 다 만든다 |

## 2. 타이포그래피
- 글꼴: **Pretendard 단일 사용**(제목·본문). 다른 글꼴 금지. 한글·영문·숫자 모두 동일.
- 위계(16:9 기준): 표지 제목 40pt / 슬라이드 제목 26pt Bold / 핵심 메시지 20pt Bold / 본문 18pt / 보조 12~14pt / 출처·푸터 9pt
- 본문 최소 12pt. 그보다 작게 써야 하면 내용을 줄이거나 부록으로 보낸다.
- 행간 1.15~1.3. 양쪽 정렬 금지(좌측 정렬).

## 3. 색
- 브랜드별 토큰은 `brands/<브랜드>.json`. **강조색(accent)은 한 슬라이드에 한 곳만** — 가장 중요한 숫자·막대 하나.
- 기본: primary(네이비) · accent(오렌지) · 회색 계열. 그라데이션·네온·무지개 팔레트 금지.
- 경고색(빨강)은 `[확인필요]` 표시 전용. 일반 강조에 쓰지 않는다.

## 4. 레이아웃 (모든 본문 슬라이드 동일 위치)
```
┌──────────────────────────────────────────┐
│ 챕터명 (11pt, accent)                       │  ← 위치 고정
│ 제목 = 이 장의 결론 한 문장 (26pt Bold)       │  ← 위치 고정
│ (부제/핵심 메시지)                            │
│                                            │
│            본문: 시각 요소 1개                 │
│      (차트 / 표 / KPI 카드 / 도식 / 불릿)      │
│                                            │
│────────────────────────────────────────────│
│ 출처: ○○  |  발행 법인명               페이지 │  ← 위치 고정
└──────────────────────────────────────────┘
```
- 좌우 여백 4.5% 이상. 요소 사이 간격은 일정하게.
- **제목은 주제어가 아니라 결론 문장**: "시장 규모" ✕ → "국내 시장은 3년간 연 18% 성장" ○ (40자 이내)
- 한 장 = 메시지 1개 + 시각 요소 1개. 불릿은 3개 이내, 각 60자 이내.
- 표는 8행 이내, 초과하면 부록으로.

## 5. 차트
- **반드시 네이티브 PowerPoint 차트**(데이터 편집 가능). 도형으로 그린 차트·이미지 차트 금지.
- 단위 표기 필수, 출처 표기 필수, 축 눈금선 제거, 데이터 레이블 직접 표기.
- 유형 선택: 추세=선, 비교=막대, 구성비=도넛(항목 5개 이하), 순위=가로막대.
- 강조할 막대 하나만 accent, 나머지는 회색.
- 3D·그림자·장식 효과 금지.

## 6. 금지 목록 ('AI 티' 제거)
- 의미 없는 아이콘 나열, 이모지, 스톡 이미지 장식
- "혁신적인", "획기적인", "새로운 패러다임" 같은 수식어
- 모든 장에 같은 카드 3개 반복
- 근거 없는 수치·가짜 로고·가짜 인용
- 한 장에 차트 2개 이상, 강조색 2곳 이상

## 7. 수치·사실 표기
- 숫자는 천 단위 쉼표, 단위 명시(원/만원/억원, %, %p 구분).
- 기준 시점 명시: "2026.09 기준", "추정", "계획".
- 출처가 없거나 확인 안 된 수치·인명·직함·지분은 `[확인필요]`를 붙인다(빨간색으로 표시되고 빌드 시 목록 출력).
- 사실 / 추정 / 가정을 구분해 표기한다.
