# 디자인 시스템 (공통)

모든 덱에 적용하는 고정 규칙. 덱마다 바꾸지 않는다. 바꿀 때는 이 파일을 고치고 `lessons-log.md`에 사유를 남긴다.

## 0. 원칙: 3초 룰
- 슬라이드는 읽는 문서가 아니라 **보는 화면**이다. 청중이 3초 안에 요지를 잡아야 한다.
- **장마다 주인공(One Hero)은 하나**: 큰 숫자, 차트, 카드 묶음, 도식 중 하나. 나머지는 조용히 받친다.
- **여백은 비용이 아니라 권위**다. 빈 곳을 채우려 하지 않는다.

## 1. 포맷과 산출 모드
| 모드 | 용도 | 규격 | 도구 |
|---|---|---|---|
| **A. PPTX** | 보고·제출·정기 보고서·상대가 편집본을 요구할 때 | 16:9 / A4 가로·세로 | `tools/build_deck.py` → .pptx + PDF |
| **B. HTML** | 현장 발표·피칭·강의 | 16:9 (1280×720) | `tools/build_html.py` → .html(폰트 내장) + PDF |
| **C. 개요** | 기획 단계 | — | 스토리라인 표 + 발표자 노트 |
- **기관 제출은 지정 양식이 최우선.** 양식이 없으면 A4 PDF.
- IR: 현장 발표 = B, 사전 송부 = PDF, 상대가 편집본 요구 = A.

## 2. 타이포그래피
- 글꼴: **Pretendard 단일 사용**. 다른 글꼴 금지. HTML은 폰트를 파일에 내장한다(Google Fonts 호출 금지 — 오프라인 발표장에서 깨짐).
| 요소 | PPTX(pt) | HTML(px, 1280×720) |
|---|---|---|
| 표지 제목 | 40 | 60 |
| 슬라이드 제목(결론 문장) | 26 Bold | 34 ExtraBold |
| 핵심 메시지 | 20 Bold | 28 Bold |
| 큰 숫자(KPI) | 40 | 64~120 |
| 본문 | 18 | 22~24 |
| 보조 | 12~14 | 15~18 |
| 출처·푸터 | 9 | 13 |
- 본문 최소: PPTX 12pt / HTML 18px. 더 작게 써야 하면 내용을 줄이거나 부록으로 보낸다.
- 좌측 정렬, 한국어는 단어 단위 줄바꿈(keep-all).

## 3. 색 — 60·30·10
| 비율 | 역할 | 토큰 |
|---|---|---|
| 60% | 바탕(Ground): 흰색·밝은 회색 | `background`, `surface` |
| 30% | 구조(Structure): 제목·표 머리·강조 패널 | `primary` (네이비) |
| 10% | 포인트(Pop): 핵심 숫자 하나, 강조 막대 하나 | `accent` (오렌지) |
- **포인트 색은 한 장에 한 곳만.**
- **어두운 배경은 표지와 마무리 장에만.** 간지·본문은 밝은 배경.
- 그라데이션·네온·무지개 팔레트 금지. 경고색(빨강)은 `[확인필요]` 전용.
- 법인별 값은 `brands/<브랜드>.json`.

## 4. 레이아웃
```
┌──────────────────────────────────────────┐
│ 챕터명 (accent)                             │  ← 위치 고정
│ 제목 = 이 장의 결론 한 문장 (40자 이내)        │  ← 위치 고정
│                                            │
│        본문: 주인공 시각 요소 1개              │
│                                            │
│────────────────────────────────────────────│
│ 출처: ○○  |  발행 법인명               페이지 │  ← 위치 고정
└──────────────────────────────────────────┘
```
### 레이아웃 어휘 (spec `type`)
| type | 형태 | 쓰는 때 |
|---|---|---|
| `cover` / `closing` | 어두운 배경 + 큰 제목 | 시작·끝 |
| `section` | 큰 번호 + 챕터명 | 챕터 전환 |
| `agenda` | 번호 목록 | 목차 |
| `kpi` | 큰 숫자 카드 1~4개(테두리 없음) | 핵심 지표 |
| `bullets` | 핵심 메시지 + `키워드: 짧은 구` 불릿 | 주장과 근거 |
| `chart` | 차트 + 우측 해설(60/40 분할) | 추세·비교·구성비 |
| `table` | 비교표(우리 열 강조) | 경쟁 비교·조건 |
| `compare` | 전/후, A/B 두 칼럼 | 변화·대안 비교 |
| `process` | 3~5단계 + 방향 화살표 | 절차·일정·자금 사용 |
- **같은 레이아웃을 연속으로 쓰지 않는다**(간지 제외). 빌더가 경고한다.
- 제목은 주제어가 아니라 결론 문장: "시장 규모" ✕ → "국내 시장은 3년간 연 18% 성장" ○

## 5. 문구 밀도 (Anti-Word-Soup)
- 문단 금지. 세 문장 이상의 줄글은 쓰지 않는다.
- 불릿: **`키워드: 짧은 구`** 형식, 장당 4개 이내, 각 40자 이내(권장 25자).
- 카드 안 문구: 3~6단어. 쉼표로 절을 잇지 않는다.
- 군더더기 제거: "~하기 위해", "~를 통해", "~할 수 있도록" 삭제.
- 장수는 브리프에서 먼저 정한다. 넘치면 장을 나누지, 글자를 줄이지 않는다.

## 6. 차트
- PPTX: **네이티브 PowerPoint 차트**(더블클릭하면 엑셀 데이터 편집). 도형·이미지 차트 금지.
- HTML: SVG 차트. 수치는 spec에서 고치고 다시 빌드한다.
- 단위·출처 필수, 눈금선 제거, 데이터 레이블 직접 표기, 강조 막대 하나만 accent.
- 추세 = 선, 비교 = 막대, 구성비 = 도넛(5항목 이하), 순위 = 가로 막대.

## 7. 모션 (HTML 모드)
- 등장 시 1회만: 요소 순차 등장, 막대 성장, 선 그리기, 숫자 카운트업.
- 반복·회전·튀는 장식 모션 금지. 동작 줄이기 설정(prefers-reduced-motion)을 켠 환경에서는 모션이 꺼진다.

## 8. 금지 목록 ('AI 티' 제거)
- 의미 없는 아이콘 나열, 이모지, 스톡 이미지 장식
- "혁신적인", "획기적인", "새로운 패러다임" 같은 수식어
- 모든 장에 같은 카드 3개 반복, 같은 레이아웃 연속
- 근거 없는 수치·가짜 로고·가짜 인용
- 한 장에 차트 2개 이상, 포인트 색 2곳 이상

## 9. 수치·사실 표기
- 천 단위 쉼표, 단위 명시(원/만원/억원, %, %p 구분), 기준 시점("2026.09 기준", "추정", "계획").
- 출처가 없거나 확인 안 된 수치·인명·직함·지분은 `[확인필요]` → 빨간색 표시 + 빌드 시 목록 출력.
- 사실 / 추정 / 가정을 구분해 표기한다.
